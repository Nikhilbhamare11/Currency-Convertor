# Currency Convertor

A simple and responsive **Currency Converter** built using **HTML, CSS, and JavaScript**. This project demonstrates the core logic of currency conversion using manually defined exchange rates instead of an external API.

## Features
* Convert one currency to another.
* Supports multiple currencies.
* Responsive and clean user interface.
* Instant conversion on user input.
* Country flags displayed for selected currencies.
* Built without any third-party API.

## 🛠️ Technologies Used
* HTML5
* CSS3
* JavaScript (Vanilla JS)

## How It Works
This project uses **manually defined exchange rates** stored in the JavaScript files. When a user selects the source and target currencies and enters an amount, the application calculates the converted value using the predefined conversion rates.

Since no external API is used, the exchange rates remain fixed until they are manually updated in the source code.

## Getting Started
1. Clone the repository:
```bash
git clone https://github.com/your-username/Currency-Convertor.git
```
2. Open the project folder.
3. Launch `index.html` in your web browser.
No additional installation or dependencies are required.

## Limitations

* Exchange rates are **static** and do not update automatically.
* This project is intended for learning and practice purposes.
* Real-world currency values may differ from the manually stored rates.
